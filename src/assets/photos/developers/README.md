# Developer photos

Drop each team member's photo in this folder using the exact filenames below
(the Developers page already points to these paths in
`src/app/data/developers.data.ts`). JPG or PNG both work — just keep the
filename the same or update the `photo` field in that file to match.

For best results, use a square photo (at least 300×300px) — the app displays
it inside a circular frame. If a photo is missing or fails to load, the app
automatically falls back to `placeholder-avatar.svg` so the layout never
breaks.
