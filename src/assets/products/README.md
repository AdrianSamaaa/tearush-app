# Product images

Each drink in `src/app/data/products.data.ts` uses `assets/products/<product-id>.jpg`.
The images here are illustrations generated for every drink (plus `custom-drink.jpg`
for "Customize My Drink"), 480×480 JPEG, ~11 KB each.

To use real photos, replace a file with a square photo using the same filename.
Admins can also set any product's image to a full `https://…` URL in Manage Products.
If an image is missing, the app shows a cup icon instead.
